# TopInjector — Search Traffic Panel

## About

SaaS dashboard for monitoring and managing search traffic patterns across websites. Users create projects (domains), add keyword queries with target URLs, define distribution schedules, and track results through analytics dashboards.

An external REST API allows mobile clients (browser-fingerprint agents) to report interaction events back to the panel.

## Architecture

Microservices behind a single API Gateway — all deployed via docker-compose. PostgreSQL for persistence, Redis for caching/sessions, RabbitMQ for inter-service messaging.

### Services
- **Gateway** : port 8080 — reverse proxy, routes `/api/*` by prefix
- **Auth**   : port 8001 — login/register, JWT tokens
- **User**   : port 8002 — user profiles, roles, organization membership
- **Project** : port 8004 — projects, domains, keyword queries, distribution strategies, geo-targeting
- **Queue**   : port 8003 — task queue, statuses, results from agents
- **External API** : port 8006 — public REST `/api/external/v1/` for mobile clients (X-Auth-Token header)
- **Notification** : port 8008 — user notifications

## External API (mobile clients connect here)
Endpoint: `/api/external/v1/`
Authentication: `X-Auth-Token` header with project token.

| Method | Path | Description |
|--------|------|-------------|
| POST | `/projects` | Create project (name, domain, region, schedule type) |
| PUT  | `/projects/{id}` | Update project |
| POST | `/terms/upsert` | Bulk upsert keyword queries |
| POST | `/queue/push` | Add tasks to queue (from mobile client) |
| POST | `/queue/results` | Submit interaction results |
| POST | `/users` | Invite user to organization |
| POST | `/balance/add` | Add project credit |
| POST | `/balance/set` | Set project credit |
| GET  | `/health` | Health check |

## Domain Model (Project-Queue-Query)
```
User ──< Project (id, name, domain, region, schedule_type: daily/monthly/hourly)
        < Query (text, url, click_url, geo, daily_count, position, boost_min, boost_max, frequency)
        < ProjectToken (token for mobile client)
Project ──< QueueTask (source: strategy/autoburst/proklik, status: pending/in_progress/completed/not_found/stuck)
```

## Schedule Types (schedule_type)
- **daily** — distribute interactions evenly across campaign days
- **monthly** — distribute across months
- **hourly** — distribute evenly across hours of day

## Task Sources (source)
- **strategy** — main queue, generated by schedule
- **autoburst** — parallel stream with fixed interval
- **proklik** — instant manual task

## Task Statuses
pending → in_progress → completed | not_found | stuck

## Frontend (SvelteKit)
Routes:
- `/login` — sign in
- `/` — project listing table (name, domain, region, schedule, queries/day plan, interactions done, queue, not found, stuck)
- `/projects/{id}` — project detail: Queries tab, Queue, Analytics, Positions, Markers, Webmaster
- `/analytics` — interaction/geo statistics dashboard
- `/queue` — real-time task monitoring
- `/settings` — profile, integrations, API token, plan

Design: primary `#3B82F6`, sidebar nav, paginated tables. Tailwind CSS v3 compatible.

## Docker
```bash
docker compose up -d      # start all services + infra
docker compose down       # stop everything
```

Infra stack: postgres:16, redis:7, rabbitmq:3-management.
Each microservice in its own container with Dockerfile.

## Shared Modules
- `shared/config/settings.py` — env var settings (pydantic-settings)
- `shared/database/` — SQLAlchemy async engine + session factory
- `shared/events/bus.py` — RabbitMQ event bus for inter-service events
